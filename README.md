# 총공 글 종합기

디시인사이드 갤러리의 지정 기간 게시글을 수집해 제목의 대괄호 분류 또는 사용자 조건에 따라 종합하는 웹 앱입니다.

## 로컬 실행

```powershell
npm.cmd install
npm.cmd start
```

브라우저에서 `http://localhost:3000`에 접속합니다.

## Vercel 배포

1. 이 프로젝트 전체를 GitHub 저장소에 올립니다.
2. [Vercel](https://vercel.com/)에 로그인하고 **Add New → Project**에서 해당 GitHub 저장소를 가져옵니다.
3. Framework Preset은 **Other**로 둡니다. 별도의 Build Command나 Output Directory는 지정하지 않아도 됩니다.
4. Deploy를 누릅니다. `vercel.json`에서 게시글 수집 API의 최대 실행 시간을 300초로 지정하고, 갤러리 검색 API는 30초로 지정합니다.
5. 배포가 끝나면 Vercel이 제공한 주소로 접속해 갤러리 검색과 짧은 기간 수집을 테스트합니다.

환경 변수나 별도 데이터베이스는 필요하지 않습니다.

## 서버리스 API 페이지 분할

- `/api/scan`은 한 번의 요청에서 기본 50페이지를 검사한 뒤 현재 페이지와 날짜 종료 판정 상태를 반환합니다.
- 브라우저는 반환된 다음 페이지와 상태를 이용해 API를 자동으로 다시 호출합니다. 중간 결과는 화면에 표시하지 않고 브라우저 메모리에 누적하며, 실제 종료 조건에 도달한 뒤 한 번에 결과를 표시합니다.
- 요청이 느려져 함수 실행 시간이 235초에 가까워지면 Vercel의 300초 제한에 걸리지 않도록 해당 배치를 먼저 반환하고 다음 요청에서 이어갑니다. 따라서 느린 상황에서는 50페이지보다 적게 처리한 뒤 이어갈 수도 있습니다.
- 날짜 종료 조건은 요청이 나뉘어도 유지됩니다. 시작일 이전 게시글만 있는 페이지가 3회 연속 나오거나, 실제 빈 페이지가 2회 연속 나오는 등 기존 종료 조건을 만족할 때만 최종 결과가 표시됩니다.
- 배치 사이에는 브라우저 탭을 닫거나 새로고침하지 마세요. 진행 중인 상태와 아직 표시되지 않은 결과는 브라우저 메모리에 있기 때문에 탭을 닫으면 해당 수집은 중단됩니다.

## 수집 방식

- **총공 종합**: 제목의 대괄호 안 내용을 기준으로 자동 분류합니다.
- **사용자 설정 종합**: 조건을 여러 개 등록하고, 대괄호 유무와 관계없이 제목 전체에서 조건을 찾습니다.
- 사용자 설정 종합에서 조건 하나만 일치하면 해당 조건 그룹에, 2개 이상 일치하면 `기타`에 한 번만 분류합니다.
- 사용자 설정 종합에서는 말머리 필터를 적용하지 않습니다.
- **앞뒤 공백 무시**와 **영어 대소문자 무시** 옵션을 제공합니다.

## 기본 수집 분류 규칙

- `[지각]`, `[각개]`는 분류에서 무시합니다.
- `[질문]`이 포함된 게시글은 수집에서 제외합니다.
- 의미 있는 대괄호가 하나면 해당 그룹으로 분류합니다.
- 의미 있는 대괄호가 둘 이상이면 `기타`로 분류합니다.
